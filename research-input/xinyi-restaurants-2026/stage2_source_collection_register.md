# Stage 2 來源蒐集登錄

版本：stage2-v0.1  
開始日期：2026-07-18  
狀態：進行中；禁止形成研究結論

## 已核准研究設計

- 樣本方案：方案 A，110 家店點樣本＋去重網站子樣本。
- 本輪平台：Perplexity／GeoCheck 證據層；不代替三平台 UI 研究。
- 量測單位：網站根網域；門市差異保留於店點表。
- 正式期間：核准後 14 日內，最終起訖日於正式 API 前凍結。
- 研究輸出：不產生優化建議、行動清單或效果預估。
- API 使用量：逐次事件與彙總須獨立備份。

## 來源蒐集層次

1. 候選來源發現：Brave Web Search，每店 1 次，僅產生 URL 線索。
2. 原頁驗證：直接開啟候選官方頁，核對名稱、門市、地址、營業／內用與來源類型。
3. 政府資料核對：取得並封存 TFDA 或相應正式資料快照。
4. 樣本凍結：保留排除理由、共用網域群組與正式輸入 SHA-256。
5. 正式 AI 量測：只對凍結後去重網站清單執行。

## 本階段禁止事項

- 不得將搜尋結果摘要當成原始來源。
- 不得把候選 URL 直接標成官方網站。
- 不得將沒有網站的店點記為 GEO 0 分。
- 不得使用本階段資料撰寫餐廳能見度結論。
- 不得因網站難抓而只保留數位成熟品牌。

GeoCheck Developer API 技術文件

面向現代 AI Agent、產品後端與自動化分析系統的客觀 GEO 引用量測開發者指南。一次呼叫，同步取得四大官方生成式搜尋引擎的原生回答與真實引用證據。

首次呼叫 API

GeoCheck API 採用標準 RESTful 設計與非同步任務輪詢協議。您可以透過官方 TypeScript SDK 或直接使用 cURL / Python 於任何環境中快速發起觀測。

3 步驟快速驗證

  1. 先登入 API 控制台 確認帳戶已開通存取資格；只有已開通的帳戶能建立 API 金鑰。
  2. 傳送 POST /v1/measurements 攜帶 Idempotency-Key 與受測品牌官方網址。
  3. 取得 202 Accepted 後，依 Retry-After 建議輪詢 GET /v1/measurements/{id} 獲得四大引擎結果。
# 1. 建立觀測任務 (POST /v1/measurements)
curl --fail-with-body --max-time 30 -X POST https://platform.lslabs.tw/v1/measurements \
  -H "Authorization: Bearer $GEOCHECK_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d '{
    "input": { "type": "url", "url": "https://example.com" },
    "locale": "zh-TW"
  }'

# 2. 輪詢結果 (GET /v1/measurements/{measurement_id})
curl --fail-with-body --max-time 30 -X GET https://platform.lslabs.tw/v1/measurements/msmt_81a2b3c4 \
  -H "Authorization: Bearer $GEOCHECK_API_KEY"
// @geocheck/sdk is not published to npm yet - see the SDK section below.

const client = new GeoCheckClient({
  apiKey: process.env.GEOCHECK_API_KEY!

// 建立任務並自動輪詢四引擎結果

console.log(result.engines);
import os, time, uuid, requests

BASE = "https://platform.lslabs.tw"
HEADERS = {
    "Authorization": f"Bearer {os.environ['GEOCHECK_API_KEY']}",
    "Idempotency-Key": str(uuid.uuid4()),
    "Content-Type": "application/json"
}

created = requests.post(
    f"{BASE}/v1/measurements",
    headers=HEADERS,
    json={"input": {"type": "url", "url": "https://example.com"}, "locale": "zh-TW"},
    timeout=30
)
if created.status_code != 202:
    raise SystemExit(f"create failed: {created.status_code} {created.text}")

measurement_id = created.json()["measurement_id"]
deadline = time.monotonic() + 600

while time.monotonic() < deadline:
    res = requests.get(f"{BASE}/v1/measurements/{measurement_id}", headers=HEADERS, timeout=30)
    if res.status_code == 200:
        print(res.json())
        break
    if res.status_code in (409, 429):
        time.sleep(float(res.headers.get("Retry-After", 5)))
        continue
    raise SystemExit(f"poll failed: {res.status_code} {res.text}")
else:
    raise SystemExit("timed out before the measurement reached a terminal state")

身分認證

所有對 Developer API 的呼叫均須在 HTTP 標頭中提供 Bearer Token：

HTTP HEADER
Authorization: Bearer gck_live_xxxxxxxxxxxxxxxxxxxxxxxxxxxx
金鑰安全須知： API 金鑰以 gck_live_ 為前綴。金鑰在控制台建立時僅於彈窗中完整展示一次，後端僅保存安全哈希與椒鹽（Pepper），絕不保存明文。若金鑰遺失請直接撤銷並重新建立。

錯誤代碼與處置建議表

GeoCheck API 遵循標準 HTTP 狀態碼規範，並於回應主體中附帶具體的 code 與 message。

狀態碼 錯誤代碼 (code) 可能原因 排查與處置建議
400 Bad Request invalid_request 請求格式錯誤或缺漏必要欄位。 檢查 JSON 語法、受測網址是否為合法之 http(s):// 網域名稱。
401 Unauthorized auth_required 未提供金鑰、金鑰無效或已被撤銷。 核對 Authorization 標頭是否帶有正確的 Bearer gck_live_... 金鑰。
402 Payment Required payment_required 目前週期可用輪數已耗盡。 前往 控制台 查看配額餘額或升級進階方案。
403 Forbidden trial_not_started 帳戶尚未開通方案權益。 前往 控制台 確認目前帳戶的開通狀態。
404 Not Found not_found 找不到指定的 Job ID 或 Measurement ID。 確認 ID 是否正確，或該筆結果是否已過期被系統清理。
409 Conflict result_not_ready 四引擎仍在搜尋與量測中。 正常非同步狀態。請讀取 HTTP Retry-After 標頭秒數並稍候重試。
410 Gone content_deleted 該觀測結果已由客戶端主動指示刪除。 依隱私規範該內容已永久抹除，系統僅保留墓碑紀錄。
429 Too Many Requests rate_limited 呼叫頻率超過速率上限。 降低平行連線數，並依 Retry-After 進行指數退避（Exponential Backoff）。
503 Service Unavailable service_unavailable 上游搜尋引擎繁忙或系統維護中。 請稍候重試。若持續發生請聯絡技術支援團隊。

速率與配額限制

為確保四大官方搜尋引擎的穩定度與資源公平分配，平台對每個帳戶施加輪次配額與速率限制。 Developer API 目前為 Private Beta，實際數值由帳戶權益決定，本文件不列固定分層。

  • 目前配額：登入 Console 的「用量」頁可看到已用、預留、可用輪次與重置時間。
  • 目前速率限制：每個回應都會帶 X-RateLimit-Limit、X-RateLimit-Remaining 與 X-RateLimit-Reset；請以這三個標頭為準，不要在程式中寫死 RPM。
  • 超出限制：回傳 429 Too Many Requests 並附 Retry-After（秒）。請依該值退避重試，不要固定間隔重送。
  • 不扣量情境：四家引擎未全數成功的觀測判定失敗，不佔用配額，但仍計入速率限制。

定價與計量原則

四引擎直連量測架構

不同於市面上單純轉售模型的中繼平台，GeoCheck 堅持官方 API 直連（Official Direct-Link）。每次觀測皆同步啟動 4 家頂級 AI 搜尋能力：

全成才扣量原則 (Atomic Settlement)

在商業量測情境中，任何一家搜尋引擎的缺漏都會導致橫向評比失真。為此，後端採用原子化結算（Atomic Settlement）：

  • 四家全成（4/4）：任務標記為 succeeded，正式結算並自租戶扣除 1 輪額度。
  • 任一失敗（<4/4）：任務標記為 failed，系統釋放預留額度，客戶帳本零扣款。但為方便除錯，回應中仍會包含已成功的 partial_results 供開發者排查。

顯式冪等性機制 (Idempotency)

發起量測時必須提供 Idempotency-Key 標頭（建議使用 UUID v4）。

若發生網路連線逾時（Timeout）或客戶端重試，傳送相同的 Idempotency-Key 將安全返回原先已建立的任務資訊，保證絕不會重複排程、絕不重複扣除額度。

非同步輪詢與生命週期

由於四大官方搜尋引擎執行即時網頁索引用時約 6~14 秒，API 採用高效能非同步輪詢設計：

  1. POST /v1/measurements 回傳 202 Accepted 與 measurement_id。
  2. 客戶端每隔 2~3 秒發送 GET /v1/measurements/{id}。
  3. 量測尚未完成時，伺服器回傳 409 Conflict (result_not_ready) 與 Retry-After: 2。
  4. 全數完成時，伺服器立即回傳 200 OK 與四大引擎原生回答、引用 URL 矩陣。

網頁存取與 WAF / 反爬蟲診斷指南

GEO 量測的隱形瓶頸：目標站點的爬蟲防護
過於激進的 WAF、Cloudflare Turnstile 或完全依賴客戶端渲染的 SPA，可能讓 AI 官方搜尋引擎（ChatGPT Search / Perplexity / Gemini）在造訪時被攔下，進而出現「0 次官方引用」或無法解析實體。這裡不列比例數字：我們尚未公開可引用的樣本與取樣方法，請以你自己網站的實際回應為準。

1. AI 搜尋引擎與爬蟲如何運作？

OpenAI、Google、Perplexity 與 Anthropic 在執行即時聯網檢索時，皆會透過其專屬 User-Agent 節點抓取目標網頁 HTML。現代反爬蟲系統（如 Cloudflare Bot Management、Akamai、DataDome）常依據下列特徵進行防護：

  • TLS/JA3/JA4 指紋識別：檢測客戶端 TLS Client Hello 握手特徵是否符合典型瀏覽器。
  • 瀏覽器環境指紋（Headless Detection）：檢測 navigator.webdriver、Canvas/WebGL 渲染指紋與音訊上下文。
  • 挑戰頁阻斷（JS Challenge / CAPTCHA）：若目標網域對非住宅 IP 預設開啟 Turnstile 質詢，AI 爬蟲將無法通過驗證碼，導致內容讀取失敗。

2. 站長自我排查檢查清單（Checklist）

檢查項目檢驗方式修正建議
Robots.txt 規則 檢查 /robots.txt 是否 Disallow 官方 Bot 允許 OAI-SearchBot、PerplexityBot、Google-Extended、ClaudeBot 造訪核心公開頁面。
WAF 白名單放行 觀察 WAF 阻擋日誌是否有各大 AI ASN 將各大官方 AI 引擎宣告之 IP 範圍或已驗證機器人（Verified Bots）加入防火牆穿透規則。
伺服器端渲染 (SSR) 使用 curl -sL <URL> 檢視原始 HTML 避免關鍵品牌主張與商品資訊純依賴客戶端 JavaScript 動態渲染；確保靜態 HTML 即包含核心文案。
HTTP 狀態碼合規 檢查爬蟲造訪時是否回傳 403 或 503 避免對雲端機房 IP 段一刀切封鎖，造成合法 AI 搜尋引擎無法建立來源佐證。

3. GeoCheck 平台的自身安全與防爬機制

GeoCheck 開發者平台亦實施完整的企業級防護架構，確保 API 不被惡意濫用：

  • 嚴格 CORS 邊界：禁止任何 Wildcard (*) CORS，保護租戶憑證安全。
  • 時序安全比對 (Timing-Safe Token Verification)：所有 API 金鑰與管理 Token 均採用加密常數時間比對，阻絕時序側信道攻擊（Timing Attacks）。
  • 智慧速率防禦：多層級 IP 與 Token 雙重計流，阻擋暴力探測與惡意排程重放。

資料保存與隱私刪除合規

依據歐盟 GDPR 及企業隱私合規規範，GeoCheck 實施嚴謹的資料生命週期管理：

  • 保存與清理：結果保存與清理範圍會在帳戶開通時由 Console 與服務條款顯示；公開文件不在此承諾固定天數。
  • 主動抹除端點：客戶端可隨時呼叫 DELETE /v1/measurements/{id}。執行後伺服器回傳 204 No Content，所有搜尋快照與文字回答即刻永久刪除，後續再度查詢將回傳 410 Gone 墓碑標記。

Python 呼叫範例

這段程式可以直接複製使用：金鑰取自環境變數，每個請求都有 timeout，非 2xx 會停下來而不是繼續輪詢。

PYTHON
import os, time, uuid, requests

BASE = "https://platform.lslabs.tw"
API_KEY = os.environ["GEOCHECK_API_KEY"]  # fail fast if unset
HEADERS = {
    "Authorization": f"Bearer {API_KEY}",
    "Idempotency-Key": str(uuid.uuid4()),
    "Content-Type": "application/json"
}

# 1. Create. Always pass a timeout: a stalled socket otherwise hangs forever.
created = requests.post(
    f"{BASE}/v1/measurements",
    headers=HEADERS,
    json={"input": {"type": "url", "url": "https://example.com"}, "locale": "zh-TW"},
    timeout=30
)
if created.status_code != 202:
    raise SystemExit(f"create failed: {created.status_code} {created.text}")

measurement_id = created.json()["measurement_id"]

# 2. Poll with a deadline. 409 means still running; 429 must honour Retry-After.
deadline = time.monotonic() + 600
while time.monotonic() < deadline:
    res = requests.get(f"{BASE}/v1/measurements/{measurement_id}", headers=HEADERS, timeout=30)
    if res.status_code == 200:
        print(res.json()["engines"])
        break
    if res.status_code in (409, 429):
        time.sleep(float(res.headers.get("Retry-After", 5)))
        continue
    raise SystemExit(f"poll failed: {res.status_code} {res.text}")
else:
    raise SystemExit("timed out before the measurement reached a terminal state")

適用服務與開放狀態

本頁說明 LS-Labs Platform 開發者 API 的使用規則草案。公開文件可直接閱讀；API 存取資格由帳戶權益決定。目前尚未開放付款，不因建立帳戶、登入或取得 API 金鑰成立付費訂閱。

服務內容與交付

平台接受符合 API 契約的觀測請求，以非同步工作產生結果。取得存取資格後，可依技術文件查詢工作狀態與結果。完整成功、部分結果、失敗與未知具有不同意義；沒有資料不代表品牌未被提及。

觀測受模型、時間、輸入與可用來源影響。平台提供量測工具，不承諾搜尋排名、引用、流量或營收。正式付費服務的交付期限與失敗處理，會在開放前列入交易條件。

帳戶與允許用途

請提供正確的帳戶資料並妥善保管登入憑證與 API 金鑰。你應具有提交資料及委託處理的權利，不得未經授權存取他人資料、干擾系統、規避用量限制或利用服務處理違法內容。請勿提交密碼、金流憑證或無權提供的個人資料。

計費與交易成立

付費服務採先購買儲值點數、再按實際完成的觀測扣點。儲值金額範圍、扣點標準與計算範例以購買當時公開的儲值與計費說明為準；交易於你在 Portaly 結帳頁完成付款、且本平台收到付款完成通知時成立。技術文件中的範例額度與上游成本紀錄不構成報價。

扣點標準調整時，會先在計費說明公告並標示生效日期；已購得的點數仍可依原約定使用，不追溯收取先前未約定的費用。

點數規則

  1. 使用範圍：點數僅限購買帳戶用於 LS-Labs Platform 本身提供的服務，不能用於支付其他商家、平台或第三方的商品或服務。
  2. 不得轉讓：點數不得轉讓、贈與、出售、出借、合併至其他帳戶或作為擔保。
  3. 不得兌換現金：點數不得兌換現金、提領或轉換為其他支付工具，也不計利息。未使用付費點數依退款與申訴申請退款，是返還原付款，不屬兌換現金。
  4. 使用期限：付費取得的點數不設使用期限，不因一段時間未登入或未使用而失效或歸零。本平台目前不發放免費或贈送點數；日後如有，會在發放時另行標示使用期限，且該部分不得退款。
  5. 扣點順序：日後同時持有贈送與付費點數時，先扣即將到期的贈送點數，再扣付費點數。
  6. 退款：未使用的付費點數可隨時申請退款，按 1 點新台幣 1 元返還，不收退款手續費。已依約完成觀測所扣的點數不予退還；錯誤或重複扣點經查明後補回或退款。詳細流程見退款與申訴。
  7. 帳戶停用與服務終止：你停用帳戶或本平台停止提供服務時，未使用的付費點數依退款規則返還，不因帳戶停用而沒收。因違反本條款而被限制使用時，仍返還未使用付費點數，但依法得請求的損害賠償不在此限。
  8. 查詢：正式開放時，控制台提供點數餘額、購買、扣點與退款紀錄查詢。
  9. 性質：點數是本平台自有服務的預付使用額度，不是電子票證、電子支付帳戶或可在其他地方使用的儲值工具。

資料、停用與變更

資料處理方式見隱私權政策。你可停止提交新請求，並依文件使用結果刪除功能或聯絡客服申請處理。為處理資安事件、違法使用或系統故障，平台可能限制存取；若涉及付費點數，仍返還未使用部分與依法應返還的款項。

正式條款會標示版本與生效日期，影響既有交易的變更將另行通知，不以修改網頁追溯改變已成立的交易。

LS-Labs Platform 退款與申訴

草案更新日期：2026-09-20

開放前草案：尚未開放付款。正式交易條件確認並完成金流審核前，不接受付費訂單。

目前狀態

LS-Labs Platform 尚未開放付款。本頁為預付額度、按用量扣款方案的退款政策草案，待適用規範確認與金流審核完成後實施。目前不提供付費訂閱的續約或取消扣款操作。

未使用餘額

你可隨時申請退還未使用的實付餘額，不必先用完額度。不收退款手續費，也不扣除金流手續費。可退款額為實際付款加上應返還的錯誤扣款，扣除已依約完成服務的費用及先前已退款金額；不重複返還同一款項。已使用部分按執行當時約定的價格計算，不因退款而改以較高價格重算。

實付餘額不設使用期限，不因未登入或帳戶停用而沒收。平台停止提供服務時，會通知並辦理未使用款項返還。對已使用部分的扣款有爭議時，可一併提出查核；依法應退還更多款項者，依較有利於消費者的規定辦理。

提出帳務或服務申訴

如對付款紀錄有疑義，或遇到重複付款、未授權交易、金額不符、未交付結果等情況，請寄信至下方客服信箱，提供訂單編號（如有）、交易日期、帳戶聯絡信箱及問題說明。不要寄送完整卡號、安全碼、密碼或 API 金鑰。

數位服務與解除契約

數位服務不因名稱就一律排除七日解除權。若交易適用法定合理例外，須在提供服務前清楚告知排除範圍，並取得消費者事先同意。單純登入、取得金鑰或閱讀本頁，不代表同意放棄法定權利。

未符合例外要件時，仍依適用法令辦理。即使已取得適法同意，也不排除未交付、重複扣款、錯誤計費或服務瑕疵所生的退款與救濟權利。

查核與返還方式

收到退款通知後，會查核訂單、付款與交付紀錄，列明退款金額及計算方式。未使用餘額退款原則上於收到通知次日起十五日內辦理返還；依法解除服務契約者，依消費者保護法第十九條之二，自收到解除通知次日起十五日內返還已支付的對價，不以內部審核完成日重新起算。

退款原則上循原付款方式辦理；原管道無法退回時，會聯絡確認可行且可核對付款人身分的返還方式。銀行實際入帳時間可能不同，我們會提供退款處理紀錄與協助查詢，不以銀行作業排除法定返還義務。部分完成與失敗的計費規則會在正式計費說明中揭露；未交付、重複或錯誤扣款經查明後，返還相應款項。

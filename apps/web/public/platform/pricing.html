LS-Labs Platform 計費說明

草案更新日期：2026-09-20

按實際用量計費

LS-Labs Platform 提供生成式搜尋引擎的回答與引用觀測 API。新方案採按用量計費，不沿用固定月費訂閱方案。目前沒有可購買的付費方案，也不會因瀏覽文件或登入控制台而產生付款。

預付服務額度

新方案優先採預付額度、按實際用量扣款，須完成適用規範確認及金流審核後才會開放。額度僅供原帳戶使用本平台提供的服務，不可轉讓、支付其他商家或提領；未使用款項可依退款政策申請返還。實付餘額不設使用期限，不因停止使用而歸零，不自動儲值或續扣。

正式開放時會提供實付餘額、扣款明細及退款紀錄查詢。若依法須提供履約保障，會在收款前揭露實際保障機構、方式、期間與查詢管道；目前尚未完成這些安排。

開放前會公布的交易資訊

正式開放前，本頁會列出計價單位、新台幣單價、稅額是否包含於售價、費用計算範例、付款時點、付款方式、交付方式與期限，以及部分完成、失敗和退款的處理方式。這些交易條件確定前，不接受付費訂單。

用量與付款的差別

控制台目前顯示的可用額度與使用紀錄是服務存取資訊，不是帳單、儲值餘額或已付款證明。按用量計費也不代表原價轉售上游 API 成本；收費公式會另行明確公布。

交易憑證

目前由個人營運，尚未開放付款。付費開放時將提供訂單與付款紀錄；是否開立統一發票依實際稅籍狀態及適用法令辦理，並在付款前揭露。不以個人身分作為免除稅務義務的理由。

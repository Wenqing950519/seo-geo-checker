快速開始：30 秒發起首次量測

透過 cURL 或 Python 發起四大引擎並行量測。帶入 Idempotency-Key 可保障完全冪等不重複扣量。

cURL Example 
curl -X POST https://platform.lslabs.tw/v1/measurements \
  -H "Authorization: Bearer $GEOCHECK_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d '{"input": {"type": "url", "url": "https://example.com"}, "locale": "zh-TW"}'
Python Request Example 
import requests, uuid

response = requests.post(
    "https://platform.lslabs.tw/v1/measurements",
    headers={
        "Authorization": "Bearer gck_live_your_key_here",
        "Idempotency-Key": str(uuid.uuid4()),
        "Content-Type": "application/json"
    },
    json={
        "input": {"type": "url", "url": "https://example.com"},
        "locale": "zh-TW"
    }
)
job = response.json()
print("Measurement initiated:", job["measurement_id"])

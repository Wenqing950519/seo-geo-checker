回應

每個引擎一個欄位

回應裡的 engines 陣列有四個元素，各自帶回答、引用與狀態。完整結構見技術文件。

answer

回答原文

引擎回答的完整文字，不摘要、不改寫。

citations[]

引用來源

引擎列出的來源網址與標題，依引擎原始順序。

status

逐引擎的狀態

任務從 queued 走到 succeeded 或 failed。任一引擎最終失敗，任務標 failed，已完成的引擎放在 partial_results。

Idempotency-Key

重送不重複

同一個鍵重送只建立一次任務。四個引擎全部完成才扣點，失敗不扣。

整合

兩個請求

  1. 1
    POST /v1/measurements

    帶 API 金鑰與 Idempotency-Key 建立任務，回 202 與 measurement_id。

  2. 2
    GET /v1/measurements/:id

    處理中回 409，完成後回 200 與四個引擎的結果。

curl -X POST https://platform.lslabs.tw/v1/measurements \
  --max-time 30 --fail-with-body \
  -H "Authorization: Bearer $GEOCHECK_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d '{"input": {"type": "url", "url": "https://example.com"}, "locale": "zh-TW"}'
import requests, uuid

res = requests.post(
    "https://platform.lslabs.tw/v1/measurements",
    headers={
        "Authorization": "Bearer " + API_KEY,
        "Idempotency-Key": str(uuid.uuid4()),
        "Content-Type": "application/json",
    },
    json={"input": {"type": "url", "url": "https://example.com"}, "locale": "zh-TW"},
    timeout=30,
)
job = res.json()
print(job["measurement_id"], job["status"])

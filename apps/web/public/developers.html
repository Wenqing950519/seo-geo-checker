實際模型以每次回應的 model 欄位為準。

  1. POST /v1/measurements

    建立觀測，回 202 和 measurement_id。同一個 Idempotency-Key 重送，不會重複建立。

  2. GET /v1/measurements/:id

    處理中回 409，完成回 200。四家的回答和引用都在 engines 裡。

cURL
# 建立觀測
curl -X POST https://platform.lslabs.tw/v1/measurements \
  --max-time 30 --fail-with-body \
  -H "Authorization: Bearer $GEOCHECK_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d '{"input": {"type": "url", "url": "https://example.com"}, "locale": "zh-TW"}'

# 取回結果，處理中回 409
curl https://platform.lslabs.tw/v1/measurements/$MEASUREMENT_ID \
  --max-time 30 --fail-with-body \
  -H "Authorization: Bearer $GEOCHECK_API_KEY"

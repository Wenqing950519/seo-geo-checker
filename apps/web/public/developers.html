為企業級 GEO 監測打造的開發者基礎設施

以可追溯的結果結構呈現觀測資料。公開範圍、可用引擎與資料保存設定會在開通時由 Console 顯示。

四引擎結果結構

回應會按引擎保留狀態與可取得的引用資料；沒有成功結果時，不以零分或空白冒充已完成。

全成才扣量原則

扣量與結果狀態的語意會由 API 契約與 Console 顯示；partial_results 保留已完成部分，不能視為完整觀測。

TypeScript 整合介面

技術文件說明型別、冪等鍵與非同步輪詢。取得存取資格後，再依文件與 Console 提供的方式整合。

資料範圍與刪除

保存、刪除與可匯出資料的範圍須以現行技術文件與帳戶開通內容為準，不在行銷頁承諾固定天數。

只需 3 行程式碼，
搞定多引擎 GEO 觀測

使用 @geocheck/sdk，您可以將複雜的並發呼叫、任務輪詢、延遲等待與錯誤降級化繁為簡。

  • 完整 TypeScript 型別推導，自動提示四引擎結構化欄位。
  • 自動處理非同步 Job 輪詢狀態與 HTTP 409 Retry-After。
  • 支援網址 (URL) 自動分析或自然語言 Prompt 直觀觀測。 
import { GeoCheckClient } from "@geocheck/sdk";

const client = new GeoCheckClient({ 
  apiKey: process.env.GEOCHECK_API_KEY! 
});

// 發起跨 4 大搜尋引擎的觀測任務
const accepted = await client.createMeasurement(
  { input: { type: "url", url: "https://example.com" }, locale: "zh-TW" },
  crypto.randomUUID()
);

// 自動輪詢並等待四家引擎全成結果
const result = await client.pollMeasurement(accepted.measurement_id);

console.log(result.engines); // [OpenAI, Gemini, Perplexity, Anthropic]
curl -X POST https://platform.lslabs.tw/v1/measurements \
  -H "Authorization: Bearer gck_live_xxxxxxxxxxxx" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: $(uuidgen)" \
  -d '{
    "input": {
      "type": "url",
      "url": "https://example.com"
    },
    "locale": "zh-TW"
  }'
import requests, uuid

api_key = "gck_live_xxxxxxxxxxxx"
headers = {
    "Authorization": f"Bearer {api_key}",
    "Content-Type": "application/json",
    "Idempotency-Key": str(uuid.uuid4())
}

# 建立觀測任務
response = requests.post(
    "https://platform.lslabs.tw/v1/measurements",
    headers=headers,
    json={"input": {"type": "url", "url": "https://example.com"}, "locale": "zh-TW"}
)
job = response.json()
print("Job created:", job["measurement_id"])

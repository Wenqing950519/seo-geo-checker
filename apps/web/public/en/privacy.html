GeoCheck privacy policy

Updated September 10, 2026

Google data

When you choose to connect Google Search Console, GeoCheck requests only the webmasters.readonly read-only permission. It uses this to display daily clicks, impressions, click-through rate and average position for the website you select. Signing in to the Developer Console with Google uses only your name and email and does not request access to Search Console.

Data retention and deletion

The Search Console refresh token is encrypted and stored only on the server. Daily aggregates are kept for up to 13 months. Disconnecting in the Dashboard immediately deletes the refresh token and the data imported for that project. GeoCheck does not sell Google data, use it for advertising audiences or give it to unrelated third parties.

Google API Limited Use

GeoCheck’s use of information obtained through Google APIs complies with the Google API Services User Data Policy, including its Limited Use requirements.

GeoCheck 隐私权政策

更新日期：2026-09-10

Google 数据

当你主动连接 Google Search Console 时，GeoCheck 仅请求 webmasters.readonly 只读权限，用于显示你选定网站的每日点击、展示次数、点击率 与平均排名。Developer Console 的 Google 登录仅使用姓名和电子邮箱，不请求 Search Console 权限。

保存与删除

Search Console 刷新令牌 只在服务器端以加密形式保存；每日汇总最多保存 13 个月。你在 Dashboard 断开连接后，刷新令牌 和该项目导入的数据会立即删除。GeoCheck 不把 Google 数据出售、用于广告受众或提供给无关第三方。

Google API Limited Use

GeoCheck 对从 Google API 取得的信息之使用遵循 Google API Services User Data Policy，包括 Limited Use 要求。

GeoCheck 隱私權政策

更新日期：2026-09-10

Google 資料

當你主動連接 Google Search Console 時，GeoCheck 僅請求 webmasters.readonly 唯讀權限，用於顯示你選定網站的每日點擊、曝光、CTR 與平均排名。Developer Console 的 Google 登入僅使用姓名與 email，不請求 Search Console 權限。

保存與刪除

Search Console refresh token 只在伺服器端以加密形式保存；每日彙總最多保存 13 個月。你在 Dashboard 解除連線後，refresh token 和該 Project 的匯入資料會立即刪除。GeoCheck 不把 Google 資料出售、用於廣告受眾或提供給無關第三方。

Google API Limited Use

GeoCheck 對從 Google API 取得的資訊之使用遵循 Google API Services User Data Policy，包括 Limited Use 要求。

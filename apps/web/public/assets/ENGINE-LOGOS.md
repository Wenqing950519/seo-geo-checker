# 四家引擎 logo 來源

四個檔案都取自各公司自己發布的檔案，2026-10-21 擷取；只改了 `viewBox`／`role`／`aria-label`，沒有重畫。先前的版本是 Simple Icons 描圖，已取代。

| 檔案 | 來源 | 使用限制 |
|---|---|---|
| `openai.svg` | OpenAI 設計指南（https://openai.com/brand/）提供的 Blossom 標誌檔 `Blossom_Light.svg`；本檔只取其中一個花型路徑並裁到標誌邊界 | 單色呈現（這裡用 `currentColor`），不加顏色與效果，留白不擠，不能當作我們自己的主品牌標誌 |
| `googlegemini.svg` | Google 自家靜態檔 https://www.gstatic.com/lamda/images/gemini_sparkle_v002_d4735304ff6292a690345.svg（Gemini 頁面使用的 sparkle） | 保留原漸層，不改色 |
| `claude.svg` | Anthropic 的 Claude 文件站 favicon https://platform.claude.com/favicon.svg；本檔去掉底色方塊，只留標誌路徑與官方色 `#D97757` | 不改色、不變形 |
| `perplexity.svg` | Perplexity 官網 favicon https://www.perplexity.ai/favicon.svg（原檔即是 potrace 描邊版，含黑底方塊） | 原樣使用；perplexity.ai 的品牌資源頁位於 Cloudflare 人機驗證之後，沒有取得向量版標誌 |

這些是各公司的商標，只用來標示「API 呼叫了哪一家引擎」，不表示合作或背書。

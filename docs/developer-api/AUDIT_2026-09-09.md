## 結論

`/v1` 的 fixture HTTP 合約與四家官方前置 API 都已通過；這證明目前帳號、model ID、搜尋工具、parser 與單次固定四家流程可用，不等於 SDK 或正式多租戶服務已完成。官方 smoke 同一題各呼叫一次、無 retry，四家都回成功與搜尋證據。去識別的逐家用量見 `evidence/official-smoke-2026-09-09.json`。

單輪上游成本為 **TWD 1.54～2.88**（USD 0.0488794～0.0911962，換匯 31.535），低於 D-030 原推論 TWD 4 約 **28.1%～61.5%**，也未觸發 TWD 4.5 重估門檻。這是 `n=1` 的成本區間：只有 Perplexity 回傳 provider-reported 總成本；OpenAI、Anthropic 依實際 token／search 數乘官方牌價，Google 因只回 total tokens 且搜尋免費額度狀態未知而保留上下界。

## 本次已修補

- `POST /api/test-provider`、`POST /api/test-search-provider`、`POST /api/search-context` 與 `GET /api/rate-limit-state` 現在都要求 `X-Admin-Token`；未設定 token 也不會降級成公開端點。
- `/v1` 回應移除 tenant ID、上游成本與原生 provider metadata，並加 `no-store`、無 wildcard CORS、`nosniff`；未知內部錯誤只回泛化 500，不再被誤報成 400 或洩漏訊息。
- 四家 adapter 收集 token、搜尋次數、response/model metadata 與版本化成本；Gemini Interactions 明確送 `store:false`；provider body 上限 2 MiB、逾時 45 秒。
- Bearer／admin token 改用 SHA-256 後固定長度比較；`DEVELOPER_API_MODE` 拼錯會拒絕啟動，不會靜默落回 fixture。
- URL 模式目前不抓網站；輸入先拒絕 credentials、localhost、任何 IP literal 與非預設埠，為未來 crawler 接入保留安全邊界。

既有 A 服務也做了不改商業語意的修補：所有回應增加 `nosniff`、拒絕 iframe、referrer 與權限政策；lead 網址只接受 HTTP(S)，不再把聯絡資料重複累積在無上限記憶體陣列，過大／錯誤 JSON／寫入失敗也不再洩漏內部錯誤。

## 人工拍板門檻

1. 決定首發 SDK 語言、套件名稱、版本與 polling／retry 契約；目前 `packages/sdk` 沒有 client，無 SDK 可測。
2. 決定正式認證與 tenancy（key 發行、hash-at-rest、scope、rotation、revoke）及 Account／Project 邊界。
3. 決定每 provider attempt/search/token 上限、整輪 timeout、retry 次數、per-key 與全域 TWD budget／熔斷值，以及 A audit／lead 的分散式 anti-abuse 門檻；這些會改成功率、成本與正常使用阻力。
4. 決定 B 結果與 A lead PII 的保存／刪除／備份／稽核期限及儲存位置；之後才能建立正式 D1 schema、atomic quota ledger、job lease 與 outbox，並淘汰本機無期限 JSONL。
5. 若 URL 模式要真正抓取，先批准 SSRF 威脅模型與 DNS pinning／redirect revalidation／egress policy；目前只由 hostname 產題，不做網路擷取。

## 驗證

- `npm.cmd run test:developer-api`：通過 application、HTTP、四家 adapter、成本 null／range、2 MiB response cap 與 D1 store 測試。
- `npm.cmd test`：完整既有回歸通過；它證明本機程式路徑，不能替代正式部署、SLA 或研究效度。
- `npm.cmd audit --omit=dev`：2026-09-09 查得 0 個已公告漏洞；這不涵蓋自寫邏輯、供應鏈未公告問題或外部服務設定。
- `git diff --check`、evidence JSON 重算與 tracked-secret pattern scan 通過；package 沒有 lint 或 typecheck script，故不能宣稱兩者已驗證。

## 證據與計價來源

實測使用 GPT-5.6 Luna、Gemini 3.5 Flash-Lite、Sonar、Claude Haiku 4.5 的官方介面與搜尋工具。牌價與行為依 [OpenAI GPT-5.6 Luna](https://developers.openai.com/api/docs/models/gpt-5.6-luna)、[OpenAI API pricing](https://developers.openai.com/api/docs/pricing)、[Gemini 3.5 Flash-Lite](https://ai.google.dev/gemini-api/docs/models/gemini-3.5-flash-lite)、[Gemini pricing](https://ai.google.dev/gemini-api/docs/pricing)、[Perplexity pricing](https://docs.perplexity.ai/docs/getting-started/pricing) 與 [Anthropic pricing](https://platform.claude.com/docs/en/about-claude/pricing)。匯率採[中央銀行 2026-09-08 美元兌新台幣銀行間收盤 31.535](https://www.cbc.gov.tw/tw/lp-645-1-1-60.html)；Google Interactions 預設保存、除非 `store=false`，依 [Interactions API overview](https://ai.google.dev/gemini-api/docs/interactions-overview)。

最強反證是：固定四家採「全數成功」後，整體可靠度會低於任一家；一次全綠 smoke 無法估算 P95 latency、失敗率或吸收失敗輪的真實成本。正式 go/no-go 至少要先有上限已批准的重複樣本與故障注入，不能用本次成功直接宣稱可公開營運。

本次沒有部署，因此 HSTS、CSP、反向代理 header 信任、WAF／Bot 規則與正式 log redaction 尚未在 Render／Cloudflare 驗證；`X-Frame-Options` 等程式層標頭只有本機證據。這是部署驗收缺口，不應被 0 個 npm advisory 掩蓋。

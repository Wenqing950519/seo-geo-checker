## 最重要的反方

四家全成才收費容易說明，但四家各自可靠不等於組合可靠。純示例：若各家成功率均98%且互相獨立，整輪約92.2%；這不是實測，實際還有共同故障與重試。已確認的D-029不更改，但每成功輪成本必須含失敗工作，不能只加四張成功帳單。

一題×四家的優點是成本與輸出邊界清楚；最大弱點是只能描述這個問題的觀測，不能代表品牌整體表現。多題能擴大觀測範圍，卻不是免費增加功能：題目數會增加呼叫、延遲與全成風險。四題×四家等於16次首次邏輯觀測，不能沿用四次呼叫的成本假設。

## 停止與交接門檻

複審後使用者已依D-031確認P2的商品粒度與優先序：一輪一題、固定四家；prompt有問題直接採用，沒有才生成。P2剩餘生成方式、歧義輸入與品質門檻仍未定；另須依HANDOFF處理P1定位、P3試用／付費時間、P4預算及P5保存政策，不把此次答覆當作全部核准。特別是註冊、驗證與可用服務時間不同時，7天何時起算須明示，不能讓候補等待消耗試用。

數值限制、客群、KPI、資料庫及成功品質gate仍是候選，不因此次複審升格決策。正式上線另需四家實際模型／搜尋能力與條款驗證、授權成本樣本、安全測試、還原演練及使用者告知；目前不宣稱可上線。

# P1 可見度構念訪談工作紀錄

> 本文件記錄使用者在引導過程中的理解與暫定原則。除非另行寫入 `docs/DECISION_LOG.md`，不得視為完整方法規格或正式研究決策。

## C-001 可見度與正確性分離

- **狀態**：使用者已接受，待整體構念定稿後再決定是否升格為正式決策。
- **使用者初步理解**：品牌被明確提及，或在伴隨的引用來源中獲得支持，可構成基礎可見度；明確推薦且具有引用支持屬進一步表現。錯誤資訊不應得到有效表現，但應在報告揭露並盡可能追查來源。
- **確認後的工作原則**：
  - 錯誤提及仍保留為「曾被看見」的曝光事件。
  - 同一筆觀察的正確性另標為錯誤、部分正確、正確或無法驗證。
  - 錯誤提及不算「合格／正確的可見度」，但不得從原始資料刪除。
- **方法理由**：若直接排除錯誤提及，會隱藏「看得到但看錯」的風險，並使可見度結果只剩成功案例。

## 尚未確認的相關提案

- 「提及」「推薦」「引用支持」「正確性」應分開記錄，不先合成一個分數。
- 只有來源卡出現品牌、答案正文未提及品牌時，暫列為「來源曝光」，不直接算品牌在答案中的可見度。
- 引用只能描述為伴隨或支持提及／推薦；不能僅由輸出反推引用造成推薦。
- 「SEO 帶動 GEO」目前只能列為待驗證假設，不得預設因果。

## C-002 品牌層可見度與門市驗證

- **狀態**：品牌層與地域正確性分離原則已獲使用者接受；抽樣含義仍待後續定稿。
- **使用者目前理解**：對「信義區有什麼餐廳推薦」這類問題，回答出現「鼎泰豐」即可構成品牌可見度；連鎖品牌不必明確列出特定門市。獨立店因品牌與單店高度重合，提及店名即代表該店被看見。
- **可操作化方向**：
  - 主要實體候選為「餐飲品牌／商業實體」，而非網站根網域。
  - 連鎖品牌只要在回答正文被實體對齊地提及，不要求回答指定分店。
  - 門市資料用於驗證該品牌在研究地域內至少有一間符合資格且營業中的店點。
  - 獨立店以同一品牌實體規則處理；不是另設一套較嚴格或較寬鬆的計分規則。
- **已確認的地域錯誤處理**：若回答提及品牌，但研究期間內沒有符合資格的信義區店點或店點已歇業，仍保留品牌曝光；地域正確性判為錯誤，且不算合格可見度。
- **錯誤追查方向**：白皮書可以保存並檢查引用頁、頁面日期、門市真值、來源衝突與實體錯置。只有證據能直接支持時才能確認錯誤來源；否則原因標為 `unknown` 或待驗證解釋，不得直接宣稱某來源污染或造成模型輸出。
- **尚待釐清**：品牌層抽樣如何避免同品牌多門市重複增加權重。
- **語言邊界**：「在指定查詢中觀察到品牌可見度」不等於已證明獲客、轉換或商業效果。
